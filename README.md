# HOSHIZORA — 自分だけのプラネタリウム

場所・日時を自由に変えて星空を探索する、GitHub Pagesで動く静的Webアプリです。**GitHub Freeの公開リポジトリとPagesだけで公開可能**で、YAML/Actions/外部データベース/有料APIキーは不要です。

## 特徴

- 東京・大阪・札幌・京都・那覇・ロンドン・ニューヨーク・シドニーから観測地を選択。任意の緯度・経度も入力可能
- ブラウザに許可すれば現在地から観測可能（HTTPSサイトのみ。サーバーに送信しません）
- 任意日時の星空、+/-1時間・1日、今夜21時、時間早送り
- 円形の全天図（中央が天頂。北が上、東が右。ドラッグで方位回転、ホイールやボタンで拡大縮小）
- 主要な恒星と星座線、太陽・月・水星〜海王星の概算位置
- 星のラベル、表示等級、観測対象の高度・方角、天文学の豆知識
- 表示設定・観測場所をブラウザ内保存、画像(PNG)保存、PC/スマホ対応

## 新しいGitHubリポジトリへの公開手順（隠しフォルダなし）

1. GitHubで新しいリポジトリ `hoshizora-lab` を作成し、**Public** を選択します。
2. このZIPを解凍し、リポジトリの **Code → Add file → Upload files** に次をアップロードしてコミットします。
   - `index.html`
   - `style.css`
   - `astro.js`
   - `app.js`
   - `favicon.svg`
   - `stars.js`
   - `README.md`（任意）
3. **Settings → Pages → Build and deployment** を開いて、Source に **Deploy from a branch**、Branch に **main**、Folder に **/(root)** を指定し **Save**。
4. 数分後、`https://＜GitHubユーザー名＞.github.io/hoshizora-lab/` を開きます。

以前FLAG QUESTでハマった `.github/workflows/` などの隠しフォルダは**今回不要**です。Pages の Source は **GitHub Actions** ではなく **Deploy from a branch** にしてください。GitHub Pages内で動的処理は動かさず、**利用者のブラウザのJavaScript**が星空を計算しています。

## 星表・計算の精度

- 内蔵する約120個の主な恒星の位置は **J2000座標の近似値**です。歳差・固有運動を反映していません。
- 起動時に公開星表 `Yale Bright Star Catalog` の短縮JSONをブラウザが読み込める場合、約2,000個以上の追加の恒星（明るさ2.3〜6等級）を表示できます。通信不可時も内蔵恒星は表示されます。
- 太陽・惑星は低精度の公転軌道要素による簡易計算、月も簡易モデルです。摂動・光行差・地形・大気差等は考慮していません。したがって**観測計画や望遠鏡の精密な導入には使用しないでください**。
- 等級表示スライダーは、**描画する恒星の星表上の明るさの上限**を指定します。実際に肉眼で見えるかは市街地の光害・月明かり・天候に左右されます。
- 昼間のシミュレーションも表示できますが、実際に日中の星が観測できるという意味ではありません。太陽を肉眼や望遠鏡で直接見ないでください。
- 星座線は代表的な星を使った**学習用簡略パターン**で、公式の境界線ではありません。
- 入力日時はブラウザのタイムゾーンで解釈されます。たとえば日本からロンドンを選ぶと、日時欄は日本時間のままです。示す天体位置自体は指定した瞬間におけるロンドンの空です。

## データ・ライセンス

- 星表の追加取得元: [Yale Bright Star Catalog — brettonw](https://github.com/brettonw/YaleBrightStarCatalog)（MIT / 元データ Yale Bright Star Catalog）。この星表の第三者利用規約も参照してください。
- 天文学座標変換・概算公転軌道の数式は一般に公開されている天文学的近似を参考にした独自のJavaScript実装。
- このアプリ本体のソースコードはMITライセンス（LICENSE参照）。天体名・星表等の第三者データには元のライセンスが適用されます。
- 任意のカタログ取得には第三者サイトへのHTTP通信が発生しますが、位置座標や保存設定は送信していません。現在地のブラウザ許可は観測場所の設定にのみ使います。

## 開発・ローカル確認

`index.html` を直接開いても主要機能は動きます。ローカルHTTPサーバーが必要なら `python3 -m http.server 8000` のあと `http://localhost:8000/` にアクセスしてください。

ファイル構成：

```
hoshizora-lab/
├── index.html      表示の骨格
├── style.css       レイアウトとデザイン
├── app.js          画面操作とCanvas描画
├── astro.js        天体位置の計算
├── favicon.svg     サイトアイコン
├── stars.js        主要な星の座標と星座線
├── LICENSE
└── README.md
```
